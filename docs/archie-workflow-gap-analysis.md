## Scope notes

- **Not changed:** `AGENTS.md`, `docs/governance/`, `docs/adr/`, `.github/`, the CLA files and the
  registries. Governance expansion is paused, so no ADR or governance document is added.
- **Not built:** an HTTP API for these operations (the authorization boundary is built first, as
  asked), live GitHub PR wiring for lesson publication, real Kepler ingestion (#130), the Ada
  runtime (#146, #155), and any AWS or Stage change.
- **Open dependency:** `ARCHIE_MODEL_ALIAS` has no approved LiteLLM entry. Until the founder
  approves one, synthesis stays on the deterministic baseline.
