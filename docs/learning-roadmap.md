# Learning roadmap

1. Run the containerized Research-to-Security demonstration with LiteLLM aliases.
2. Inspect structured outputs, request ID propagation, errors, and separate JSONL memories.
3. Change the aliases in .env to compare LiteLLM routes without changing provider settings here.
4. Experiment with SecurityAgent prompt-injection handling using untrusted research findings.
5. Evaluate the Amazon Bedrock AgentCore hosting and authentication compatibility for SecurityAgent before any AWS deployment.
6. Add agents only when a specific experiment needs them; retain simple REST and JSON logs until they stop meeting the learning needs.

No AWS resources are provisioned in Phase 1.
